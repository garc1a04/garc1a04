## 👨‍💻 About Me

I'm **Guilherme Garcia Monteiro**, a Computer Engineering student at Unifor and a Full-Stack Developer Intern at Vortex 🇧🇷.

I enjoy solving problems, building backend systems, and exploring different areas of software development — from REST APIs and software architecture to competitive programming, artificial intelligence, and game development.

I care about clean code, performance, and working well in agile teams.
